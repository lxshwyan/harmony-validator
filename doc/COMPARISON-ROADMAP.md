# 选型差异补齐状态

| 方向 | 当前状态 | 实际交付与边界 |
| --- | --- | --- |
| 文档与示例 | 开发分支已完成 | 行为表、兼容性说明、共享 Schema 边界、生成模型与 HTTP 消费示例 |
| 请求取消与页面生命周期 | 模拟器及真实 HTTP 已完成 | 两种入口、12 个在途取消服务端断连；真机按用户条件保持未验收 |
| Schema 安全复用 | 已完成兼容方案 | SchemaFactory 每次重新构造及派生，不改变旧可变 API；任意深拷贝/全面不可变仍未提供 |
| 模型与规则一致性 | 已完成生成工具子集 | 单一定义生成输入/输出/Patch/Schema，检查漂移；不自动分析任意手写 Model 或回调 |
| Standard Schema 接入 | 已完成 JS/TS 桥接 | 官方接口类型检查与运行测试通过；位于工具层，不宣称纯 ArkTS HAR 的原生标准接口已交付 |

| JSON Schema 完整性 | 保持明确子集 | 原有能力和严格诊断保留；完整标准语料与更多关键词是后续专项 |

详见[行为与兼容性](BEHAVIOR-COMPATIBILITY.md)、[本轮验证报告](VALIDATION-STABILITY.md)。未来完整不可变 API、任意类型推导与跨生态集成仍需单独设计；不因本轮基础方案通过就标记全部长期目标完成。
