# @hmkit/validator 1.2.0

兼容现有主入口的功能增强版本。

## 更新

- 深度局部更新支持容器、组合、Lazy 递归/相互递归及判别联合，保留原始 Schema 与判别字段检查。
- JSON Schema 新增严格导入、路径诊断、布尔 Schema；修复 oneOf 重叠、同级约束遗漏及字符串/数值边界。
- 异步批量新增并发上限与超时，取消令牌支持订阅/退订，自定义异步规则可读取请求上下文和取消通知。
- 修复嵌套上下文丢失、对象覆盖后可选标记残留、表单销毁后的依赖校验派发。
- 提供 interop、execution、composition、form 按需入口及中英文高级用法、独立消费示例。

## 验证与限制

- 263 项本地测试通过；覆盖率：行 92.83%、函数 82.67%、分支 83.86%。
- Pura 90 / HarmonyOS 6.1 API 23 模拟器：主入口与按需入口各三次进程重启、重复执行、取消状态恢复、退出重进通过。
- 模拟器首次启动曾发生生命周期超时，后续未复现，根因尚未确定；真机与真实网络适配验收未完成。
- JSON Schema 严格模式是能力预检，不是完整标准合规认证；底层网络请求需主动响应取消通知。
- 完整 HAR 增长至约 146 KiB，内部预算为 160 KiB；按需导入不承诺缩小整个 HAR。

用户选择基于当前本地及模拟器验证结果发布，保留上述限制。OHPM 提交与审核上架是两个独立阶段。

详细验证见 [验证报告](VALIDATION-1.2.0.md)，示例见 [中文指南](ADVANCED-1.2.0.md) / [English guide](ADVANCED-1.2.0-en.md)。
